#Part 1: Introduction to Software Engineering

1. What is Software Engineering and its Importance in the Tech Industry?
Software Engineering is the process of designing, developing, testing, and maintaining software systems using programming and engineering principles
Importance:
•	Solves real-world problems (e.g., health apps, education platforms).
•	Drives innovation in industries like AI, robotics, and fintech.
•	Enables digital transformation for businesses worldwide.
•	Creates career opportunities across nearly every sector.
________________________________________
2. Key Milestones in the Evolution of Software Engineering
1.	Introduction of High-Level Programming Languages (1950s–60s):
Languages like FORTRAN and COBOL made coding more accessible than machine code.
2.	The Software Crisis (1968):
As systems grew, software became hard to manage—this led to formalizing Software Engineering as a discipline.
3.	Agile Development (2001):
The Agile Manifesto introduced a flexible, team-based approach to building software that adapts to change.
________________________________________
3. Phases of the Software Development Life Cycle (SDLC)
1.	Requirement Analysis: Understand what the user needs.
2.	Design: Plan how the system will look and function.
3.	Implementation (Coding): Write the actual code.
4.	Testing: Check for bugs and issues.
5.	Deployment: Release the product to users.
6.	Maintenance: Fix issues and update features over time.
________________________________________
4. Compare and Contrast: Waterfall vs Agile Methodologies
Feature	Waterfall	Agile
Approach	Linear and sequential	Iterative and flexible
Planning	Everything upfront	Ongoing planning and adaptation
Testing	Happens after implementation	Happens continuously during development
Best for	Clear, fixed requirements (e.g., banking)	Projects with changing needs (e.g., apps)
Example Scenarios:
•	Waterfall: Government software with strict compliance rules.
•	Agile: Mobile app development that needs user feedback integration.
________________________________________
5. Roles in a Software Engineering Team
•	Software Developer :
Writes, tests, and maintains the code. Turns design into working applications.
•	Quality Assurance (QA) Engineer :
Tests the software to find bugs and ensure it meets requirements.
•	Project Manager :
Plans, coordinates, and communicates with the team to keep the project on track.
________________________________________
6. Importance of IDEs and VCS
•	Integrated Development Environments (IDEs):
Tools like VS Code or PyCharm that make writing, testing, and debugging code easier.
•	Version Control Systems (VCS):
Tools like Git and GitHub help track changes, collaborate with teams, and avoid losing work.
Why they matter:
•	Enable collaboration.
•	Prevent code conflicts.
•	Speed up development.
________________________________________
7. Common Challenges & Strategies
Challenges:
•	Debugging complex bugs
•	Changing requirements 
•	Team communication issues
Strategies:
•	Use version control to manage changes.
•	Practice code reviews and testing.
•	Use Agile methodologies to adapt to changes.
•	Maintain clear documentation and communication.
________________________________________
8. Types of Testing and Their Importance
1.	Unit Testing:
Tests individual pieces of code (like a function).
Ensures small parts work correctly.
2.	Integration Testing:
Tests how different parts work together.
Ensures modules talk to each other properly.
3.	System Testing:
Tests the entire application as a whole.
Ensures the whole system works as intended.
4.	Acceptance Testing:
Tests the app from the user's point of view.
Ensures it meets user requirements before launch.

#Part 2: Introduction to AI and Prompt Engineering

1.Define prompt engineering and discuss its importance in interacting with AI models. Provide an example of a vague prompt and then improve it by making it clear, specific, and concise. Explain why the improved prompt is more effective. 

What is Prompt Engineering?
Prompt engineering is the process of crafting effective and precise inputs (called prompts) to get accurate, helpful, and relevant responses from AI models like ChatGPT.
Think of it as “talking to AI in its language.” The better you give instructions, the better the AI performs.
________________________________________
Why is Prompt Engineering Important?
•	Improves AI accuracy: Clear prompts reduce confusion and help AI understand your intent.
•	Saves time: You get better results faster by avoiding back-and-forth clarifications.
•	Unlocks AI potential: Well-crafted prompts allow AI to write code, stories, debug errors, generate ideas, and more.
•	Boosts creativity and productivity: Especially in areas like design, programming, writing, or data analysis.
________________________________________
Example of a Vague Prompt vs. an Improved Prompt
Vague Prompt:
"Tell me about planets."
This is unclear:
•	Which planets? In our solar system? Exoplanets?
•	Do you want fun facts, scientific data, or a comparison?

Improved Prompt:
"Give me three fun facts about the planets in our solar system that a 10-year-old would enjoy."
Why the Improved Prompt Is Better:
•	Clear audience: Tailored for a 10-year-old.
•	Specific content: Fun facts about solar system planets.
•	Concise: Easy for AI to understand and stay on-topic.
